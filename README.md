# 心愿便签 (wish_notes)

一款基于 Flutter 的心愿记录与管理应用。用户可以记录、分类、筛选自己的心愿, 标记「已实现 / 未实现」; 登录后还可以把心愿保存到云端, 在心愿广场浏览他人的公开心愿并参与评论。

## 技术路线

本项目同时实现了大作业的两条基础路线, 并在此基础上做了本地与云端的数据协同:

- **路线一: 本地存储** —— 使用 sqflite 保存心愿数据, 使用 shared_preferences 保存登录 token、记住的账号等轻量配置。
- **路线二: 网络请求** —— 使用 Dio 封装 HTTP 请求, 对接培训提供的后端 API, 完成心愿的增删改查、状态修改、公开心愿与评论。
- **本地与云端协同** —— 心愿支持本地 / 云端 / 智能三种存储模式; 智能模式本地优先, 联网后自动同步。

## 已实现功能

### 心愿管理

- 创建、查看、编辑、删除心愿
- 已实现 / 未实现状态切换
- 五种分类(学习成长、生活日常、旅行探索、兴趣爱好、其他), 支持按分类筛选
- 支持按状态筛选, 默认按创建时间倒序展示
- 表单校验、删除二次确认和操作结果提示
- 空列表、加载中、网络异常均有对应提示

### 本地存储

- sqflite 建库建表, 关闭应用后数据仍然保留
- shared_preferences 保存 token、用户信息、记住的账号
- 未登录也能完整使用本地心愿功能

### 云端与社区

- 注册 / 登录 / 退出登录
- 云端心愿的上传、拉取、更新、删除与状态同步
- 心愿广场: 浏览公开心愿, 支持全部/未实现/已实现筛选, 按时间或评论数排序, 下拉刷新和本地缓存
- 心愿详情与评论: 发表评论、回复评论、删除自己的评论
- 公开心愿展示作者, 未知作者按数据来源补全或显示为匿名用户

### 交互与视觉

- 启动页、底部导航、自定义弹窗、Toast 提示
- 分类色条、分类图标、卡片状态样式
- 适配常见 Android 手机屏幕, 页面切换和返回逻辑基于 Navigator 1.0

## 技术栈

| 用途 | 技术 |
| --- | --- |
| 状态管理 | Provider (ChangeNotifier / Consumer) |
| 本地数据库 | sqflite |
| 轻量配置 | shared_preferences |
| 网络请求 | Dio |
| 路由管理 | Navigator 1.0 |
| 应用图标 | flutter_launcher_icons |

## 项目结构

```text
lib/
├── logic/          # Provider 状态模型(登录态、心愿列表)
├── models/         # 数据模型与枚举
├── repositories/   # 本地数据库与云端接口的统一数据入口
├── utils/          # 数据库、网络、SharedPreferences、时间格式化、确认弹窗、Toast 工具
├── widgets/        # 可复用组件(心愿卡片、状态标签、评论气泡、卡片容器、登录注册外壳、弹窗菜单)
├── presentation/   # 页面(启动页、导航、心愿、表单、详情、我的、登录注册)
├── app_theme.dart  # 全局主题
└── main.dart       # 入口与 Provider 注入
```
